# Howdy's Automotive

Pre-launch website for Howdy's Automotive, a mobile automotive care business launching in Conroe, Texas.

## Founding 25
The initial campaign offers 25 pre-launch Founding Memberships at $99. Checkout is intentionally disabled until a real payment provider/link is connected.

## Deploy
This is a static site. Connect this repository to Cloudflare Pages and use the repository root as the output directory; no build command is required.
